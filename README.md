# Held, one drop at a time

Running this program writes one short text to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` if set, else `/output`).

## Why this text

The published judge brief is a relaxation brief — criteria in order: (1) it relaxes the reader, slows them down; (2) calm from the text itself, shows rather than instructs; (3) craft: rhythm and pacing that hold you in one place, plain concrete gentle words; (4) it lingers: an image you can return to; (5) freshness, no stock wellness phrases. The text answers with concrete room details (kettle, sun-warmed chair, rain finding the roof) instead of instructions, a slow unhurried rhythm, and one lingering image — shoulders remembering they are not a shelf.

## How to run

```
node main.ts
```
